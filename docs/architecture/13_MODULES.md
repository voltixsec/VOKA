## Advanced Import / Export Center

Location:

```text
Settings
  → Advanced Tools
      → Import / Export Center
```

Supported imports:

- Products
- Customers
- Suppliers
- Price Lists
- Inventory
- Services

Workflow:

```text
Template
→ Upload
→ Validation
→ Preview
→ Import
```

This module is optional, web-only, and intended for advanced users. It
complements Voice and AI rather than becoming the default product experience.
